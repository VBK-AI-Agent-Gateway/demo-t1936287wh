# 坦克跳坑 Tank Hops

经典版坦克跳坑小游戏，纯原生 HTML5 Canvas + JavaScript，零依赖。

## 玩法
- 方向键 / A·D 移动，空格 / ↑ 跳跃，K / 回车开炮
- 手机用屏幕下方虚拟按钮
- 跨越 6 个陷阱坑，击碎砖块，收集油桶（+100），抵达金色旗帜通关
- 3 条生命，坠坑后在最近检查点重生

## 本地运行
直接用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
