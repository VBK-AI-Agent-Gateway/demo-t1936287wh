# app-6287wh — 月饼换足球（Mooncake → Soccer Ball）

- `index.html` — 成果展示页：原图（before.png）与替换后（result.png）左右对比
- `before.png` — 原始图片（含 3 块月饼）
- `result.png` — 成品图：中部月饼已替换为带光影与接触阴影的足球，其余月饼区域做背景融合淡化

## 处理流程

1. **检测**：金色像素（HSV 偏金黄）连通域定位 3 块月饼区域
2. **修复**：主体区域用邻域纹理回填（近邻外扩填充），其余区域向周围色调软融合
3. **合成**：程序化绘制经典黑白块足球（二十面体投影五边形 + 高斯主光 + 暗缘 + 接触阴影），超采样缩放抗锯齿
