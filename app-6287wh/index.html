SYSTEM DESIGN · v1.0

论文验证系统 · 多维度学术诚信检测平台

从传统查重升级为 引用真实性 × 文本原创性 × 图像完整性 × 逻辑/元数据一致性 四维验证：每条判定必附可解释证据链，输出「通过 / 需人工复核 / 高风险」三级结论，全流程异步、引擎与外部服务双插拔、AIGC 与图像结果仅作信号并强制人工复核入口。

四层架构4 个可插拔引擎证据链驱动判定异步任务队列Provider 可替换严格 / 标准 / 宽松三策略PDF · LaTeX · Markdown · BibTeX

0设计原则（约束映射）

约束设计落点
判定必须可解释每个引擎输出 evidence[]；融合层结论必须回链证据 ID；报告层只渲染「证据 → 结论」链，抽检可 100% 回链
AIGC / 图像结果仅作"信号"二者不直接触发"高风险"，只贡献 signal_score 且权重低（≤0.10 / 0.22 且受 confidence 折扣）；高风险结论强制附人工复核入口与 evidence_ids 清单
流程异步化、支持大文件与批量提交即返回 task_id；Celery/Redis 队列按 section/figure 分片并行；批量任务组 group_id 聚合进度
外部服务可替换策略模式 + Provider 抽象接口，配置化选择（Crossref / OpenAlex / CNKI、iThenticate / 自建库、自研 / 商用 AIGC 检测…），熔断降级 + 结果缓存
四层架构接入解析层 → 检测引擎层 → 融合决策层 → 报告接口层（见 §1）

1四层架构

④ 报告接口层（同步 HTTP）

提交 / 进度 / 报告 REST API、Webhook 回调、PDF · HTML · JSON 三种报告渲染、人工复核工作台。
POST /submissions → 202 {task_id} GET /tasks/{id} GET /tasks/{id}/report POST /tasks/{id}/review

③ 融合决策层（异步 worker）

证据聚合与聚类 → 加权融合分 → 硬规则/信号双通道 → 通过 / 需人工复核 / 高风险 三级判定 + 结构化解释生成。
evidence[] → cluster → risk=Σw·s·c → hard-rule gate → Verdict{level, reason, checklist}

② 检测引擎层（可插拔，四引擎并行）

E1 引用真实性 · E2 文本原创性（查重+AIGC） · E3 图像完整性 · E4 逻辑与元数据一致性；统一输出信封 {score, confidence, signal_only, evidence[]}。
IR ─┬→ E1 ─→ EngineResult₁ ┌→ E2(查重/AIGC) ─→ EngineResult₂ ├→ E3 ─→ EngineResult₃ └→ E4 ─→ EngineResult₄

① 接入解析层

上传 PDF / LaTeX / Markdown / BibTeX → 解析（GROBID / pandoc / pybtex…）→ 归一化 → 规范化中间表示 IR → 对象存储 + 数据库。
file → parse(OCR 兜底) → DocumentIR{metadata, sections, sentences, references, figures} → 存储/入队

关键解耦点：四层之间只通过 DocumentIR 与 EngineResult 两种数据结构通信；①②③ 全部跑在异步任务队列，④ 为同步 HTTP 层。新增文件格式只改①，新增检测维度只加②，判定策略只动③，互不牵连。

1.1 规范化中间表示（DocumentIR）

所有引擎只消费 IR，不关心原始文件格式：

{
  "doc_id": "doc_9f31",
  "metadata": {"title": "...", "authors": [...], "venue": "...", "year": 2024},
  "sections":  [{"idx": 1, "title": "Introduction", "paras": [{"id": "p1", "text": "..."}]}],
  "sentences": [{"id": "s1", "section": 1, "text": "...", "cites": ["r1", "r2"]}],
  "references":[{"id": "r1", "raw": "[1] ...", "title": "...", "doi": "10....",
                 "venue": "...", "year": 2020}],
  "figures":   [{"id": "f1", "path": "img/f1.png", "w": 800, "h": 600,
                 "caption": "...", "cited_by": ["s9"]}],
  "equations": [...], "tables": [...],
  "parse": {"ok": true, "confidence": 0.97, "engine": "grobid-0.8"}
}

2检测引擎层 · 统一输出信封

每个引擎无论内部算法如何，输出统一结构（便于融合层无差别消费）：

EngineResult = {
  engine: "e1" | "e2_text" | "e2_aigc" | "e3" | "e4",
  version: "1.2.0", provider: "crossref",
  score:      0.0–1.0,   // 风险度：越高越可疑
  confidence: 0.0–1.0,   // 该结论本身的可信度（数据源覆盖率/模型校准度）
  signal_only: bool,      // true = 仅作信号，不可单独触发高风险
  signals:  {...},        // 子信号分解
  evidence: [{id, type, severity, confidence, quote, location, source_ref}],
  latency_ms, status: ok | degraded | failed
}
E1 · 引用真实性引擎元数据核验 + 引文语义支持度

输入：IR.references、IR.sentences.cites、学科领域、策略配置。

处理流程：① 元数据规范化（DOI/标题清洗、模糊匹配）→ ② 多数据源核验 → ③ 存在性/一致性比对 → ④ 引文语义支持度验证（claim-citation entailment）→ ⑤ 证据打包。

关键算法 / 工具：

  • 元数据核验：Crossref / OpenAlex / DataCite / CNKI（Provider 抽象）；DOI 正则校验；标题 rapidfuzz ≥90 判同；撤稿检测接 Retraction Watch；期刊质量接 DOAJ / 预警名单。
  • 语义支持度：将「被引句上下文」与「文献标题+摘要」编码后做 NLI 推断（DeBERTa-mnli 微调 / sentence-transformers 阈值法），输出 entailment 概率；长引用块做多句对齐（匈牙利匹配）。

输出字段：metadata_match{found, title_ok, year_ok, venue_ok, doi_valid, source} · support_score · orphan_refs[] · missing_refs[] · retracted_flag · predatory_venue_flag

置信度：conf = 0.9·found_ratio + 0.1·(1−fuzzy_margin)；数据源命中率 <50% → conf=0.4 并标注 low_coverage（如中文期刊在 Crossref 覆盖低）。

证据示例：

{"id":"EV-E1-001","type":"missing_ref","ref":"[12]",
 "sources":["crossref","openalex"],"query":"Deep residual learning...",
 "severity":0.9,"confidence":0.92}
{"id":"EV-E1-002","type":"weak_support","ref":"[3]","nli":0.21,
 "context":"本研究显著提升了准确率[3]。",
 "ref_abstract":"...研究对象为图像分割...","severity":0.6}
E2 · 文本原创性引擎传统查重 + AIGC 概率判别（信号）

输入：IR.sentences、可选机构自建库、外部查重 API 开关。

处理流程：① 预处理（去参考文献/致谢/公式、分句、归一化）→ ② 粗筛（SimHash / MinHash-LSH 候选召回）→ ③ 精确匹配（最长公共子串、滑窗对齐）→ ④ 段落级 AIGC 判别 → ⑤ 汇总为文档级两个分值。

关键算法 / 工具：

  • 查重：pgvector/SimHash 自建库 + Provider 适配器（iThenticate、CNKI、Plagscan…）；开源底座 simhash / text-dedup。
  • AIGC：多特征交叉——perplexity（GPT-2 XL）、burstiness 句长波动、DetectGPT/Logit-Rank 假设采样；轻量分类器 + isotonic 温度校准；结果标注 model_tag + 校准日期。

输出字段：plagiarism{doc_score, matched_segments[{sent_ids, source, similarity, url}], self_ref_excluded} · aigc{doc_score, para_scores[{para_id, p_ai, ppl, burstiness, logit_rank}], signal_only}

置信度：查重 conf = 1 − 语料库覆盖缺口；AIGC conf <0.6 时强制 signal_only=true（非母语作者、术语密集文本易误判）。

证据示例：

{"id":"EV-E2-001","type":"matched_segment","src":"arxiv:1706.03762",
 "sim":0.94,"quote":"Attention is all you need...","offset":[120,189]}
{"id":"EV-E2-002","type":"aigc_signal","para":"p7","p_ai":0.87,
 "ppl":18.2,"burstiness":0.31,"signal_only":true}
E3 · 图像完整性引擎复用 / 拼接 / 篡改 + AI 生成识别（信号）

输入：IR.figures（PDF 内嵌图提取、LaTeX includegraphics 解析）。

处理流程：① 解码 + EXIF 元数据 → ② 感知哈希指纹库查重（跨论文复用）→ ③ 单图篡改取证 → ④ 拼接/复制移动检测 → ⑤ AI 生成检测 → ⑥ 多信号聚合。

关键算法 / 工具：

  • 复用：pHash/dHash（imagehash）汉明距 ≤8 判同图；ORB/SIFT 局部特征识别"裁剪/调色后复用"。
  • 篡改：ELA 误差级分析、CFA 插值一致性、PRNU 噪声残差、复制-移动块匹配。
  • 拼接：边缘光照/噪声不连续、频域残差突变。
  • AI 生成：XceptionNet 类伪造检测二分类（自部署或商用 API Provider）；标注图/曲线图另做 OCR + 坐标轴-数值一致性启发式检查。

输出字段：reuse[{fig_id, match{paper_id, fig_id, similarity, crop}}] · tamper[{fig_id, regions, method, score}] · splice_suspect[{fig_id, score, cue}] · ai_generated[{fig_id, p_ai, model, signal_only}]

置信度：子信号独立计 conf；pAI 未校准（ECE>0.1）→ conf=0.5 且 signal_only=true；ELA 单信号不可作结论，须 ≥2 信号一致才升 risk。

证据示例：

{"id":"EV-E3-001","type":"image_reuse","fig":"f2",
 "matched":"paper_x#f5","phash_dist":4,"similarity":0.97,
 "artifact":{"overlay_diff":"s3://artifacts/ev3-001.png"}}
{"id":"EV-E3-002","type":"copy_move","fig":"f3",
 "region":[210,80,140,90],"score":0.82,"method":"orb_block_match"}
E4 · 逻辑与元数据一致性引擎统计异常 · 引用网络 · 格式合规

输入：IR 全量（metadata、references、equations、tables、正文数字断言）。

处理流程：① 统计异常 → ② 引用网络异常 → ③ 格式合规 → ④ 内部矛盾扫描。

关键算法 / 工具：

  • 统计异常：正文报告值 vs 表格/图数值一致性（数字正则抽取 + 单位归一，±0.5% 容差）；描述统计合法性（SD≤0、p=0.000、均值±SD 超量纲、百分比≠100）、Benjamini-Hochberg 多重比较提醒。
  • 引用网络：自引率、文献年龄分布、期刊集中度（HHI，>70% 同刊预警）、同年同刊异常批量引用（引用堆砌 cartel）、复用 E1 的幽灵文献结论。
  • 格式合规：CSL 样式渲染比对（APA / IEEE / GB-T 7714）、盲审匿名合规（正文泄露作者/单位）、图表编号连续性、公式引用完整性。
  • 内部矛盾：摘要 vs 结论句、方法 vs 结果的 NLI 反转检测（conf<0.7 降级为提示）。

输出字段：stat_anomalies[{id, kind, detail, severity}] · citation_net{self_cite_rate, year_span, journal_hhi, implausible_cluster} · format{style, violations[]} · internal_contradictions[]

置信度：规则类 0.95（确定性）；NLI 矛盾类取模型 conf。

证据示例：

{"id":"EV-E4-001","type":"stat_inconsistency",
 "loc":"tab.2 vs 正文 L412","claim":"p=0.03","table":"p=0.30","severity":0.85}
{"id":"EV-E4-002","type":"self_cite_rate","value":0.48,
 "benchmark":"<0.20","severity":0.5}

3融合决策规则（三级判定）

3.1 证据链聚合与分类

  1. 标准化：每条 evidence → {id, engine, severity, confidence, type}。
  2. 去重 / 关联：同一现象多引擎命中 → 组成 evidence_cluster（如 E1 缺失文献 + E4 引用网络异常 → 簇 reference_fabrication）。
  3. 信号分类：decisive 硬证据 查重高相似段、图像与已发表图 pHash 相同、DOI 查无此文；signal 信号 AIGC 概率、AI 图像概率、统计启发式；contextual 上下文 格式违规、风格异常。

3.2 分数融合（加权 + 硬规则双通道）

risk_score = Σ w_i · s_i · c_i        # s=引擎 score, c=引擎 confidence
# 初始权重（按领域配置可调）
w(E1 引用真实) = 0.30    w(E2 查重)     = 0.28
w(E2 AIGC)     = 0.10    w(E3 图像)     = 0.22    w(E4 逻辑) = 0.10
# AIGC / AI 图像权重低且受 confidence 折扣 —— 体现"信号"定位

判定伪代码

def decide(results, policy) -> Verdict:
    ev   = collect_evidence(results)                 # 全量证据
    risk = weighted_score(results)                   # 融合风险分
    hard = [e for e in ev if e.type in HARD_RULES]   # 硬规则
    sig  = [e for e in ev if e.severity >= 0.75
                      and e.confidence >= 0.6]

    # —— 硬规则优先，一票触发 ——
    if exists(hard, "image_reuse_confirmed") \
       or exists(hard, "missing_ref_major") \
       or max_matched_plagiarism(results) >= 0.60:
        return Verdict("HIGH", risk, ev,
                       reason="硬证据触发", human_review_required=True)

    # 阈值: 严格 0.55 / 标准 0.65 / 宽松 0.75
    if risk >= policy.high_threshold and len(sig) >= 2:
        return Verdict("HIGH", risk, ev,
                       reason="多引擎高严重度信号汇聚", human_review_required=True)

    if risk >= policy.review_threshold \
       or any(e.engine in ("e2_aigc","e3") and e.severity >= 0.8 for e in ev) \
       or any(e.type == "format_block" for e in ev):
        return Verdict("REVIEW", risk, ev,
                       reason="存在需人工确认的信号", human_review_required=True)

    return Verdict("PASS", risk, ev, reason="未达复核阈值")

硬规则表（可配置，一票 HIGH）

证据类型阈值等级
image_reuse_confirmedpHash 相似 ≥0.95 且来源为已发表论文HIGH
missing_refDOI/标题经 ≥2 数据源查无此文HIGH
plag_segment单源相似 ≥0.60 且跨 ≥3 段HIGH
retracted_ref引用已撤稿文献 ≥1 且正文作为关键依据HIGH
stat_fabrication正文与表格数值直接矛盾HIGH
plag_segment0.30–0.60 区间REVIEW
aigc_signalp_ai ≥0.85（仅信号，永远不单独触发 HIGH）REVIEW
self_cite_rate>0.50REVIEW

策略差异：严格 = 阈值下移 + AIGC/格式权重 ×1.3；宽松 = 阈值上移 + AIGC 仅在 ≥0.9 时计入。策略随任务落 policy_snapshot，历史报告可按快照复算。

3.3 三级输出与解释生成

✓ 通过 PASS
  • 融合分 < 复核阈值
  • 无硬规则命中
  • 附各引擎分数与"未触发原因"
△ 需人工复核 REVIEW
  • 融合分 ≥ 复核阈值，或存在高严重度信号
  • 附复核清单：优先核对的 evidence_ids
  • 人工可确认 / 推翻并留痕
✕ 高风险 HIGH
  • 硬规则命中，或多引擎高严重度信号汇聚
  • 100% 关联人工复核入口
  • 结论必须可回链到具体证据

解释结构：explanation = {headline, top_reasons[{cluster, weight_contribution, evidence_ids}], counter_signals[], review_checklist[]} —— 报告层据此渲染"为什么是这个结论 + 人工应先看哪几条"。

                   caption, cited_by jsonb)

detection_tasks   (id, doc_id FK, group_id NULL, strategy(strict|standard|loose),

                   callback_url, created_at, started_at, finished_at, error)

                   score real, confidence real, signal_only bool,
                   payload jsonb, latency_ms, status)

                   confidence real, cluster_id NULL, quote text, location jsonb,
                   source_ref jsonb, artifact_uri jsonb, created_at)
                   -- location: {"page":3} | {"sent_ids":[...]} | {"fig_id":"f2","bbox":[x,y,w,h]}

verdicts          (task_id PK, level(pass|review|high), risk_score real,
                   explanation jsonb, policy_snapshot jsonb,
                   reviewed_by NULL, review_note, reviewed_at)

reports           (id, task_id FK, format(html|pdf|json), uri, created_at)

webhook_deliveries(id, task_id FK, endpoint, payload jsonb,
                   status(pending|sent|failed), retries, last_attempt_at)

-- 向量侧（pgvector，规模化后可迁 Qdrant/Milvus）
sentence_embeddings(sentence_id, doc_id, embedding vector(384))  -- 查重召回

关键索引：detection_tasks(status, group_id) · evidence(task_id, cluster_id) · references(doi) · documents(file_hash)（同文件秒级判重）。

7关键风险与缓解措施

风险影响缓解措施
误报查重误伤合理引用、跨语言同表达、AIGC 误判非母语作者 → 冤枉作者、信任崩塌 ① 排除自引/引用块/方法学通用句；② AIGC 永远 signal_only 且高阈值才进 REVIEW；③ 全部结论附证据 + 人工复核入口；④ 按领域校准阈值，用人审结果持续做混淆矩阵监控
隐私与合规未发表论文、个人信息、涉密内容外泄 → 泄密、法律风险 ① 静态加密（SSE）+ TLS1.3；② 外部 API 前置脱敏开关（默认只送 n-gram 片段/图像哈希而非全文）；③ 租户级隔离 + RBAC + 全量审计日志；④ 可配置保留期（默认 90 天自动删除）；⑤ GDPR 删除接口 DELETE /v1/documents/{id}
外部 API 限流/宕机/涨价任务堆积、结论不可用 ① 令牌桶限流 + 指数退避 + 结果缓存（同 DOI/同图哈希）；② 多 Provider 优先级故障转移（crossref→openalex→本地缓存）；③ 降级策略：外部不可用 → 子项 confidence=0.4, low_coverage，不阻塞整体；④ 熔断器 + 健康探针（GET /v1/engines）
AIGC 检测不确定性模型迭代快、改写绕过、校准漂移 → 结论被质疑 ① 定位为"信号"，权重 ≤0.10；② 报告标注 model_tag + 校准日期 + 历史准确率；③ 多特征交叉（ppl + burstiness + logit_rank）而非单模型；④ 持续收集人审 ground truth 再校准；⑤ 明示不确定性（p=0.87 → 报告写"中高倾向，需人工确认"）
图像检测技术极限高质量扩散图、语义合理拼接 → 漏报多信号投票（pHash 库 + ELA + 噪声 + AI 分类器），单信号不结论；图像指纹库持续收录已发表论文图
解析失败扫描版 PDF、复杂 TeX → 任务失败解析置信度自评，低置信 → 强制 REVIEW 并提示人工核对解析结果；OCR 兜底
批量资源挤占SLA 违约队列按优先级分道（interactive / batch）、按队列深度 HPA、子任务级进度上报

8验收标准

8.1 功能

  • 支持 PDF / LaTeX / Markdown / BibTeX 四种输入，解析成功率 ≥98%（扫描件走 OCR 路径并标注）
  • 四引擎可独立开关，单引擎挂掉不影响其余结果（部分降级 + low_coverage 标注）
  • 每条判定均可在报告中定位 ≥1 条证据（quote / location / artifact 齐全），抽检 100% 可回链
  • 同一输入 + 同一 policy 版本 → 三级判定结果可复现
  • 严格 / 标准 / 宽松三策略阈值生效，且随 policy_snapshot 快照留存
  • 人工复核可覆盖机器结论并留痕（reviewer、note、时间）
  • Webhook 签名验证 + 失败重试 + 手动补发全通

8.2 性能

  • 20 页 PDF 标准策略端到端 P50 ≤90s、P95 ≤5min（不含外部 API 排队）
  • 并发 50 提交不雪崩：队列积压可视化，按队列深度自动扩容
  • 单文件 ≤100MB、批量单组 ≤200 文件受支持（分片 + 断点）
  • API p95：提交 <300ms、进度查询 <200ms、报告 <1s

8.3 可解释性

  • 报告包含：融合分、各引擎分/置信度、top 证据簇、反向信号（若有）、人工复核清单
  • AIGC / 图像结果显式标注 signal_only 与校准信息，不允许单独触发 HIGH
  • 高风险结论 100% 关联人工复核入口与具体 evidence_ids
  • 融合权重 / 阈值配置版本化，给定 policy_snapshot 可复算历史结论

8.4 可扩展性

  • 新增引擎 = 实现 run(ir, ctx) → EngineResult + 注册，不改融合层代码（接口契约测试通过）
  • 新增外部 Provider = 新增适配器类 + 一条配置，1 天内可上线切换
  • 引擎可独立部署为 worker，单独扩缩容 / 换 GPU 资源
  • 回归：黄金样本集（已知抄袭 / 已知清白 / AIGC 改写集）每版本跑通，指标不回退
