## 2. 目标与成功指标

| 指标 | 目标值 | 度量方式 |
|---|---|---|
| 租户开通到可用时长 | ≤5 分钟 | 注册→完成组织导入时间 |

## 4. 功能需求（核心场景）

| FR-AD-01 | 建组织 | 创建部门树、添加成员 | P0 | 支持≥5级部门；成员含手机号唯一校验 |

## 5. 非功能需求（NFR）

| 类别 | 指标 |
|---|---|
| 性能 | API P99 ≤ 300ms；IM 在线 10w 连接/集群 |
| 可用性 | SaaS 99.9%；私有化支持单机降级 |
| 安全 | 传输 TLS1.2+；敏感字段 AES 加密存储；越权=0 |
| 隔离 | 租户间逻辑隔离必达，支持按租户物理隔离（大客户） |
| 兼容 | Chrome/Edge/Safari 近两版；iOS/Android App；私有化支持信创 OS |
| 可观测 | 全链路 traceId、租户级用量 metrics |

## 6. 边界与风险

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 跨租户数据泄露 | 高 | ORM 强制 tenant 过滤 + 网关注入 + 混沌测试 |
| 审批流程配置错误 | 中 | 流程模拟器 + 发布前校验 |
| IM 高并发毛刺 | 中 | 分片+限流+降级 |
| 私有化环境差异 | 中 | Helm 标准化 + 兼容矩阵 |
