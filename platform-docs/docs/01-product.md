# 阶段一：产品定位 & 功能清单

> 项目代号：**Conflux 协同平台** —— 对标钉钉的企业协同办公平台

## 1. 产品定位

| 维度 | 说明 |
|---|---|
| 一句话定位 | 面向 50–5000 人成长型企业的**多租户一体化协同办公平台** |
| 目标客户 | 成长型企业、连锁门店、制造/零售/教育行业、政企私有化客户 |
| 核心价值 | 一套账号打通通讯录、沟通、审批、考勤、文档、应用，数据安全可控 |
| 商业模式 | SaaS 订阅（免费版/专业版/旗舰版）+ 私有化 License（永久/年费） |
| 差异化 | ① SaaS 与私有化一套代码交付；② 权限细粒度到字段级；③ 审批+考勤+IM 深度联动 |
| 技术底座 | 微服务 + 消息队列 + 多租户数据隔离（行级 tenant_id + 可选独立库） |

## 2. 版本矩阵

| 版本 | 部署形态 | 适用规模 | 包含模块 |
|---|---|---|---|
| 免费版 | SaaS 公有云 | ≤50 人 | 通讯录、IM、工作台、基础审批 |
| 专业版 | SaaS 公有云 | ≤500 人 | 全模块 + 考勤、云文档 |
| 旗舰版 | SaaS / 专属云 | ≤5000 人 | 全模块 + 高级权限、开放平台 |
| 私有化版 | 客户机房/K8s | 不限 | 全模块 + AD/LDAP 集成、信创适配 |
