# 阶段六：迭代计划 —— Conflux 协同平台

## 1. 总体里程碑

| 阶段 | 周期 | 目标 | 发布物 |
|---|---|---|---|
| M0 奠基 | W1–W2 | 架构落地、多租户骨架、CI/CD | 可运行脚手架 |
| M1 通讯录+权限 | W3–W5 | 组织管理、RBAC、管理后台 | 内测版 Alpha |
| M2 IM | W6–W9 | 单聊/群聊/已读/漫游 | Beta 1 |
| M3 OA+考勤 | W10–W13 | 审批引擎、打卡、假期联动 | Beta 2 |
| M4 工作台+云文档 | W14–W16 | 待办聚合、公告、文件分享 | RC |
| M5 商业化 | W17–W18 | 计费、租户控制台、压测、安全审计 | GA 1.0 |

## 2. 迭代明细（双周 Sprint）

| Sprint | 周次 | 模块 | 关键任务 | 验收标准 |
|---|---|---|---|---|
| S1 | W1–W2 | 基建 | K8s/Compose 双环境、MySQL+Redis+MQ、tenant 拦截器、JWT、网关 | 跨租户越权测试全绿；一条 CI 流水线跑通 |
| S2 | W3–W4 | 组织 | 部门树 CRUD、成员管理、Excel 导入、可见范围 | 5000 行导入成功率≥99%；越权查询 403 |
| S3 | W5 | 权限 | RBAC、角色分配、perm_version、审计日志、管理后台框架 | 权限变更 10s 生效；审计完整 |
| S4 | W6–W7 | IM 基础 | WS 网关、会话/消息表、seq 号段、单聊收发、离线推送 | 消息不丢不重（压测10w条幂等） |
| S5 | W8–W9 | IM 进阶 | 群聊、已读回执、撤回、漫游、@提及、文件消息 | P99 送达≤500ms；漫游90天 |
| S6 | W10–W11 | OA 引擎 | 表单设计器、流程图 JSON、状态机、任务流转 | 分支/会签/或签用例 100% 通过 |
| S7 | W12–W13 | 考勤 | 考勤组、排班、GPS/WiFi 打卡、补卡、月报、假期余额 | 围栏判定准确；请假扣减事务一致 |
| S8 | W14 | 工作台 | 待办聚合、应用配置、公告+已读统计、红点 | 三类待办聚合正确；已读率准确 |
| S9 | W15–W16 | 云文档 | 文件分片上传、分享权限、版本、Yjs 协同、ES 检索 | 100MB 上传成功；越权 403 |
| S10 | W17 | 商业化 | 计费订阅、配额 429、租户控制台、租户用量 | 配额超限准确拦截 |
| S11 | W18 | 质量 | 全链路压测、越权渗透、混沌、私有化 Helm/Compose 打包、文档 | P99 达标；安全报告 0 高危 |

## 3. 团队与分工（建议 8 人）

| 角色 | 人数 | 职责 |
|---|---|---|
| 后端 | 3 | iam/org/oa/att + im/doc |
| 前端 | 2 | Web/管理后台/工作台 |
| 客户端 | 1（或跨端） | App + WS SDK |
| 测试 | 1 | 用例、越权测试、压测 |
| SRE/架构 | 1 | K8s、可观测、私有化交付 |

## 4. 风险与依赖

| 风险 | 影响 | 应对 |
|---|---|---|
| 多租户隔离漏洞 | 致命 | S1 起建立越权测试集，CI 必跑 |
| IM 长连接稳定性 | 高 | 心跳+重连+本地缓存兜底 |
| 流程引擎复杂度 | 中 | v1 仅支持分支/会签/或签，暂缓子流程 |
| 私有化环境碎片 | 中 | Helm+Compose 双打包，兼容矩阵 |
| 报价/计费变更 | 低 | 配额中心独立服务，规则可配 |

## 5. Definition of Done（通用）

| 项 | 标准 |
|---|---|
| 代码 | 评审通过、单测覆盖≥60%、无 P0/P1 静态扫描问题 |
| 多租户 | 该模块越权用例全绿 |
| 文档 | API 文档、变更日志同步 |
| 可观测 | 关键接口有 metrics + trace |
| 发布 | 灰度→全量，可回滚 |
